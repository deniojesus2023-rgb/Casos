# Casos

Funil do Caso 001: **O Segredo da Família Almeida**.

- `index.html`: página de vendas (versão original refinada, imagens embutidas).
- `desafio.html`: "O Desafio dos 10%", quiz interativo com tema escuro.
- `funnel.js`: parâmetros UTM e eventos de rastreamento.
- `assets/`: imagens das evidências com fundo recortado. Os originais com fundo branco estão em `assets/original/`.

Para ver, abra os arquivos HTML no navegador. O botão de compra ainda não tem link de checkout: defina `CHECKOUT_URL` em `index.html`.
